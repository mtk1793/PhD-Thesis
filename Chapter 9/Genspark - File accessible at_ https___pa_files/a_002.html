Chapter 9: Coordinated Control Using Hybrid AI

This chapter presents the integrated control framework for coordinating diverse power system resources using hybrid artificial intelligence approaches. Building upon the Cognitive Adaptive Power System Management (CAPSM) framework introduced in Chapter 3, this chapter details the methodologies for achieving coordinated control across heterogeneous assets including FACTS devices, EV fleets, and distributed energy resources (DERs). The hybrid AI approach combines fast, reactive control elements with deliberative optimization processes to balance multiple operational objectives while adapting to dynamic grid conditions.

9.1 Hierarchical Multi-Agent Reinforcement Learning

The coordinated control of modern power systems presents a complex decision-making problem characterized by high dimensionality, partial observability, and distributed nature. Hierarchical multi-agent reinforcement learning (HMARL) addresses these challenges by organizing control agents in a structured hierarchy that enables both local autonomy and global coordination.

9.1.1 Theory and Principles of Hierarchical Multi-Agent RL

Hierarchical multi-agent reinforcement learning extends traditional reinforcement learning by introducing multiple levels of decision-making agents with different temporal and spatial scopes. This approach is particularly well-suited for power system control problems, which naturally exhibit hierarchical structure across different voltage levels, geographic regions, and time scales.

The HMARL framework can be formalized as a collection of Markov Decision Processes (MDPs), each representing a different level of the hierarchy. For level l∈{1,2,...,L}, the MDP is defined by the tuple ⟨Sl,Al,Tl,Rl⟩, where:

Sl=state space at level l Al=action space at level l Tl:Sl×Al×Sl→[0,1]=transition function Rl:Sl×Al→R=reward function

The hierarchical structure is established through the relationship between levels, where higher-level agents provide goals or abstract actions for lower-level agents. Specifically, the action al−1 of an agent at level l−1 can be a goal state or abstract action that influences the reward function Rl of agents at level l.

9.1.2 Implementation in Power Systems Context

In the context of the CAPSM framework, the hierarchical multi-agent reinforcement learning approach is implemented across three primary levels:

  1. Device Level: Individual control agents for FACTS devices, EV chargers, and DER units that operate based on local measurements and control objectives.
  2. Regional Level: Coordination agents responsible for optimizing the operation of multiple devices within a specific grid region or microgrid.
  3. System Level: High-level agents that establish global objectives and policies to ensure system-wide stability, efficiency, and security.

This hierarchical structure aligns with the dual-process architecture of CAPSM, where the device-level agents primarily utilize System 1 (fast, intuitive) control mechanisms, while regional and system-level agents incorporate System 2 (deliberative, analytical) processes for optimization and planning.

The state space at each level incorporates different aspects of the power system:

sdevice={Vi,Ii,Pi,Qi,SOCi,statusi,...} sregional={voltage profile,loading level,available flexibility,forecasts,...} ssystem={stability margins,congestion indicators,market prices,reserve levels,...}

Similarly, the action spaces differ across levels:

adevice={set points,mode selection,on/off decisions,...} aregional={power allocation,voltage targets,operating constraints,...} asystem={regional objectives,resource prioritization,emergency responses,...}

9.1.3 Coordination Mechanisms Between Agents

Effective coordination between agents at different levels and within the same level is crucial for achieving coherent system-wide control. The CAPSM framework implements multiple coordination mechanisms:

  • Vertical Coordination (Between Levels): Higher-level agents provide abstract goals, constraints, and reference values to lower-level agents, while lower-level agents report their state, capabilities, and performance to higher-level agents.
  • Horizontal Coordination (Within Levels): Agents at the same level coordinate through information sharing, consensus algorithms, and negotiation protocols to resolve conflicts and optimize collective performance.

Mathematically, vertical coordination can be represented as a bi-directional mapping:

γdown:(sl,al)→constraintsl+1 γup:sl+1→informationl

While horizontal coordination can be formulated using consensus dynamics:

ai(t+1)=ai(t)+α∑j∈Niwij(aj(t)−ai(t))

where Ni represents the neighbors of agent i, wij is the weight assigned to the link between agents i and j, and α is a learning rate.

9.1.4 Learning Algorithms for Multi-Agent Systems

The CAPSM framework employs several specialized reinforcement learning algorithms adapted for multi-agent settings. These algorithms address key challenges in multi-agent learning, including non-stationarity, partial observability, and the credit assignment problem.

At the device level, where fast response is critical, the framework utilizes Deep Q-Networks (DQN) with extensions for multi-agent environments:

Algorithm 9.1: Multi-Agent Deep Q-Network (MA-DQN)
Initialize primary Q-networks Q_i(s,a;θ_i) and target networks Q̂_i(s,a;θ̂_i) for each agent i
Initialize experience replay buffer D_i for each agent i
For episode = 1 to M:
    Initialize system state s
    For t = 1 to T:
        For each agent i:
            With probability ε, select random action a_i,t
            Otherwise, select a_i,t = argmax_a Q_i(s_t, a; θ_i)
        Execute joint action a_t = (a_1,t, a_2,t, ..., a_N,t)
        Observe rewards r_i,t and next state s_t+1
        Store transitions (s_t, a_i,t, r_i,t, s_t+1) in D_i
        For each agent i:
            Sample mini-batch of K transitions (s_j, a_i,j, r_i,j, s_j+1) from D_i
            Set y_j = r_i,j + γ max_a Q̂_i(s_j+1, a; θ̂_i)
            Update θ_i by minimizing the loss: L(θ_i) = 1/K ∑_j (y_j - Q_i(s_j, a_i,j; θ_i))²
        Every C steps, update target networks: θ̂_i ← θ_i

Initialize local policies π_i(a|s;θ_i) and value functions V_i(s;φ_i) for each regional agent i
For iteration = 1 to M:
    Collect trajectories D_global and D_i using current policies
    Compute advantages A_global and A_i using GAE
    Update global policy by maximizing:
        L_global(θ) = E_t [ min( r_t(θ) A_global,t, clip(r_t(θ), 1-ε, 1+ε) A_global,t ) ]
        where r_t(θ) = π_global(a_t|s_t;θ) / π_global(a_t|s_t;θ_old)
    Update global value function by minimizing:
        L_V^global(φ) = E_t [ (V_global(s_t;φ) - V_target,t)² ]
    For each regional agent i:
        Update local policy by maximizing:
            L_i(θ) = E_t [ min( r_t(θ) A_i,t, clip(r_t(θ), 1-ε, 1+ε) A_i,t ) ] + β KL(π_global||π_i)

            L_V^i(φ) = E_t [ (V_i(s_t;φ) - V_target,t)² ]

9.1.6 Stability and Convergence Analysis

A critical consideration in multi-agent reinforcement learning is ensuring the stability and convergence of the learning process. This is particularly important in power systems, where control actions directly impact critical infrastructure.

The stability of the proposed HMARL framework is analyzed using Lyapunov stability theory. For a system with state s and joint action a, we define a Lyapunov function V(s) that represents the "distance" from a desired equilibrium state. The stability condition requires that the expected change in the Lyapunov function is non-positive:

E[V(st+1)−V(st)|st=s,at=a]≤−α(s)+β

where α(s) is a positive definite function and β is a small constant that allows for minor fluctuations around the equilibrium.

To ensure this stability condition is met, the CAPSM framework incorporates:

  1. Safe Policy Updates: Policy updates are constrained to ensure that the probability of violating operational limits remains below a predefined threshold.
  2. Bounded Exploration: Exploration strategies are designed to avoid actions that could lead to unstable system conditions.
  3. Fallback Mechanisms: Safety-critical components are equipped with model-based fallback controllers that activate when the learning-based controller's confidence falls below a threshold.

The convergence properties of the multi-agent learning algorithms are analyzed using replication dynamics and potential games theory. For policy gradient methods used at higher control levels, convergence is established by showing that the gradient updates follow the negative gradient of a potential function Φ:

∇θiJi(θ)=∇θiΦ(θ)

where Ji is the objective function for agent i, and θ represents the joint policy parameters of all agents.

9.2 Coordinated Control of FACTS and EVs

The coordinated control of Flexible AC Transmission System (FACTS) devices and Electric Vehicle (EV) fleets represents a key application of the hybrid AI approach within the CAPSM framework. 9.2.1 Interaction Mechanisms Between FACTS Devices and EV Fleets

FACTS devices and EV fleets exhibit complementary characteristics that can be leveraged through coordinated control. FACTS devices offer fast response capabilities for voltage support and power flow control, while EV fleets provide flexible active power consumption/injection with inherent energy storage capacity.

The interaction between these resources is established through several mechanisms:

  • Spatial Correlation: The placement of FACTS devices relative to EV charging hubs influences their ability to mutually support grid operations. By mapping the electrical proximity of these resources, the control system can identify high-value coordination opportunities.
  • Temporal Complementarity: FACTS devices can respond within cycles to milliseconds, while EV charging can typically be adjusted within seconds to minutes. This temporal diversity allows for coordinated responses across different time scales.
  • Shared Objective Functions: Both resource types contribute to common objectives such as voltage profile improvement, congestion management, and loss reduction, enabling joint optimization.

The interaction can be formalized through a coupling matrix C that captures the sensitivity of grid conditions at the locations of FACTS devices to changes in EV charging patterns:

ΔVF=C⋅ΔPEV

where ΔVF represents voltage changes at FACTS device locations and ΔPEV represents changes in EV charging power.

  3. Loss Minimization: Reduce active power losses in the transmission and distribution systems.
  4. EV Charging Satisfaction: Meet EV owner requirements for state of charge by departure time.
  5. Operating Cost Minimization: Reduce the cost of control actions and energy consumption.

9.3 Integration of DERs within the Control Framework

The integration of diverse Distributed Energy Resources (DERs) within the CAPSM control framework presents unique challenges due to their heterogeneity, distribution across the grid, and varying ownership models. This section details approaches for incorporating these resources into the coordinated control framework.

9.3.1 Incorporation of Diverse DERs into the Coordination Framework

The CAPSM framework incorporates various types of DERs, each with distinct characteristics, constraints, and capabilities:

  • Solar PV Systems: Variable generation dependent on weather conditions with rapid ramping capabilities but limited controllability (curtailment only).
  • Wind Turbines: Variable generation with some inertial response capabilities and controllable power output within available wind resource.
  • Battery Energy Storage Systems (BESS): Highly controllable with bidirectional power capability, energy constraints, and degradation considerations.
  • Flexible Loads: Demand-side resources with varying degrees of flexibility, response times, and user comfort constraints.
  • Combined Heat and Power (CHP) Systems: Dispatchable generation with coupled electrical and thermal outputs and constraints.

The integration approach follows a standardized resource abstraction model that captures the essential characteristics while hiding implementation details:

DERi=⟨Pmin,Pmax,Qmin,Qmax,Rampup,Rampdown,Ecap,Ecurr,ηch,ηdis,Cflex,τresp⟩

where the parameters represent active power limits, reactive power limits, ramping constraints, energy capacity, current energy level, efficiencies, flexibility cost, and response time.

This abstraction enables the control framework to interact with diverse DERs through a consistent interface while accounting for their unique characteristics in the optimization and control processes.

9.3.2 Handling Heterogeneous Resources and Capabilities

The heterogeneity of DERs is managed through a capability-based approach that classifies resources according to their technical abilities and response characteristics. Each DER is mapped to a capability matrix Ci,j indicating its ability to provide service j with quality level Ci,j∈[0,1].

The capabilities considered include:

  • Active power flexibility (upward and downward)
  • Reactive power support
  • Inertial response
  • Primary frequency response
  • Secondary frequency regulation
  • Voltage support
  • Congestion management
  • Black start capability

Based on this capability matrix, the control framework dynamically forms resource portfolios that collectively meet grid needs while accounting for technical constraints and economic considerations.

For resources with similar capabilities, the framework implements a merit order approach that selects resources based on cost, availability, and environmental impact. This is formulated as a constraint satisfaction problem:

where xi,j indicates whether DER i is selected to provide service j, Pi is the capacity of DER i, and Rj is the required capacity for service j.

9.4 Adaptive Control Strategies for Dynamic Conditions

Modern power systems face increasingly dynamic operating conditions due to renewable energy variability, changing load patterns, and evolving grid configurations. The CAPSM framework implements adaptive control strategies that continuously adjust to these changing conditions while maintaining system stability and performance.

9.4.1 Online Learning and Adaptation Mechanisms

The adaptive control capabilities of the CAPSM framework are built upon continuous online learning that updates control models and policies based on observed system behavior. These mechanisms enable the control system to improve performance over time and adapt to changing conditions without requiring manual reconfiguration.

The online learning framework implements multiple adaptation mechanisms:

  1. Model Parameter Updates: Continuous refinement of system models based on measured data.
  2. Policy Refinement: Gradual improvement of control policies through reinforcement learning.
  3. Feature Selection: Dynamic identification of the most informative input features for control decisions.
  4. Hyperparameter Tuning: Automatic adjustment of algorithm parameters to optimize performance.

The online model adaptation process is formulated as a recursive identification problem:

θ^t+1=θ^t+Kt⋅(yt−y^t) Kt=Pt⋅ϕt⋅(1+ϕtT⋅Pt⋅ϕt)−1 Pt+1=(I−Kt⋅ϕtT)⋅Pt⋅λ−1

where θ^t represents the estimated model parameters at time t, yt is the measured output, y^t is the predicted output, Kt is the adaptation gain, ϕt is the regressor vector, Pt is the covariance matrix, and λ is a forgetting factor that determines the balance between adaptation speed and stability.

Policy refinement is implemented through an online reinforcement learning approach that updates the Q-values based on observed transitions:

Qt+1(st,at)=Qt(st,at)+αt⋅δt δt=rt+γ⋅maxaQt(st+1,a)−Qt(st,at)

where αt is a time-dependent learning rate, δt is the temporal difference error, rt is the immediate reward, and γ is the discount factor.

9.4.2 Transfer Learning for Changing System Conditions

The adaptive control framework leverages transfer learning techniques to accelerate adaptation to new operating conditions by transferring knowledge from previously encountered scenarios. This approach is particularly valuable in power systems where the underlying physics remains constant while operating conditions change.

The transfer learning strategy addresses several types of system changes:

  • Topology Changes: Adapting to network reconfigurations due to maintenance or faults.
  • Load Pattern Evolution: Adjusting to seasonal or long-term changes in consumption patterns.
  • Generation Mix Shifts: Accommodating changes in generation technology and distribution.
  • Asset Performance Degradation: Compensating for aging equipment and changing device characteristics.

The transfer learning process involves:

  1. Source Domain Selection: Identifying previously learned domains with relevant knowledge.
  2. Feature Mapping: Creating correspondences between features in source and target domains.
  3. Model Adaptation: Adjusting model parameters to fit the target domain while preserving general knowledge.
  4. Performance Validation: Evaluating the transferred model and fine-tuning as needed.

Mathematically, the transfer learning approach can be formulated as:

minθTLT(θT)+λ⋅Ω(θT,θS)

where θT represents the model parameters in the target domain, LT is the loss function in the target domain, θS represents the model parameters from the source domain, Ω is a regularization term that encourages similarity between source and target parameters, and λ controls the strength of this regularization.

9.4.3 Resilience to Unexpected Disturbances

The adaptive control framework is designed to provide resilience against unexpected disturbances, including equipment failures, extreme weather events, and cyber-physical attacks. This resilience is achieved through a combination of predictive analytics, fast response mechanisms, and adaptive recovery strategies.

The resilience strategy encompasses three phases:

  1. Anticipation: Proactive identification of potential vulnerabilities and preparation for likely disturbances.
  2. Absorption: Rapid response to mitigate the immediate impact of disturbances when they occur.
  3. Recovery: Efficient restoration of normal operation after disturbances.

For anticipation, the framework implements a risk assessment process that continuously evaluates the system's exposure to various disturbance types:

Riski=Pi⋅Ii⋅(1−Ri)

where Pi is the probability of disturbance type i, Ii is the potential impact, and Ri is the system's inherent resilience to that disturbance type.

Based on this risk assessment, the control system allocates resources and prepares contingency plans to enhance resilience against the most critical threats.

For absorption and recovery, the framework implements adaptive emergency control strategies that coordinate available resources to maintain critical functions during disturbances and efficiently restore normal operation afterward.

9.4.4 Fault-Tolerant Control Approaches

The CAPSM framework incorporates fault-tolerant control capabilities that enable continued operation despite component failures or degraded functionality. These capabilities are essential for maintaining grid stability and service continuity in the face of equipment malfunctions, communication failures, or sensor errors.

The fault-tolerant control approach includes:

  • Fault Detection and Diagnosis: Rapid identification of faults and determination of their type, location, and severity.
  • Control Reconfiguration: Dynamic adjustment of control strategies to accommodate the fault condition.
  • Graceful Degradation: Prioritization of critical functions when operating with reduced capabilities.
  • Redundancy Management: Coordination of backup systems and alternative resources.

For critical control functions, the framework implements analytical redundancy through model-based observers that can estimate system states even when primary sensors fail:

x^t+1=f(x^t,ut)+Lt⋅(yt−h(x^t))

where x^t is the estimated state vector, f is the system model, ut is the control input, yt is the available measurement vector, h is the output model, and Lt is an adaptive observer gain matrix.

When a sensor fault is detected, the framework automatically reconfigures to use the observer estimates in place of the faulty measurements:

For actuator faults, the control allocation is dynamically adjusted to redistribute control effort among the remaining healthy actuators:

u=B†⋅v

where u is the vector of actuator commands, v is the desired control effect, and B† is the pseudo-inverse of the control effectiveness matrix B, which is updated when actuator faults are detected.

9.4.5 Self-Healing Capabilities through AI

The CAPSM framework implements self-healing capabilities that enable the power system to autonomously recover from disturbances and failures. These capabilities leverage AI techniques to diagnose problems, reconfigure the system, and restore service without requiring manual intervention.

The self-healing process follows a structured approach:

  1. Damage Assessment: Evaluate the extent and impact of the disturbance.
  2. Service Prioritization: Identify critical loads and essential services.
  3. Resource Inventory: Determine available generation, storage, and control capabilities.
  4. Reconfiguration Planning: Develop an optimal strategy for system restoration.
  5. Sequential Restoration: Implement the restoration plan with continuous feedback and adjustment.

The AI-driven self-healing capability draws on several techniques:

  • Knowledge-Based Systems: Encoding expert knowledge about recovery procedures.
  • Reinforcement Learning: Developing optimal restoration strategies through experience.
  • Graph Theory Algorithms: Identifying optimal network reconfiguration paths.
  • Multi-Objective Optimization: Balancing speed of recovery with stability and security.

The restoration planning problem is formulated as a sequential decision-making process:

where at represents the restoration action at time t, st is the system state, R is the reward function that quantifies restoration progress, γ is a discount factor, and f, g, and h represent system dynamics and constraints.

9.5 Approaches for Balancing Multiple Control Objectives

Modern power system operation involves numerous, often competing objectives, including stability, efficiency, cost, environmental impact, and customer satisfaction. The CAPSM framework implements sophisticated approaches for balancing these multiple objectives to achieve optimal overall system performance.

9.5.1 Multi-Objective Optimization Formulations

The multi-objective control problem in the CAPSM framework is formulated as a formal multi-objective optimization:

minuF(u)=[f1(u),f2(u),...,fm(u)] subject to: gi(u)=0,i=1,2,...,p hj(u)≤0,j=1,2,...,q

where u represents the control vector, fi are the individual objective functions, gi are equality constraints, and hj are inequality constraints.

The primary objectives considered in the framework include:

  1. Stability Enhancement: Improving transient and voltage stability margins.
  2. Loss Minimization: Reducing active power losses in the transmission and distribution systems.
  3. Cost Optimization: Minimizing operational and control costs.
  4. Congestion Management: Alleviating transmission and distribution bottlenecks.
  5. Emissions Reduction: Minimizing greenhouse gas and pollutant emissions.
  6. Customer Satisfaction: Meeting quality of service requirements and user preferences.

Each objective is formulated mathematically and normalized to enable meaningful comparison and aggregation:

f~i(u)=fi(u)−fiminfimax−fimin

where fimin and fimax are the minimum and maximum values of objective i within the feasible region.

9.5.2 Pareto Optimality in Power System Control

The concept of Pareto optimality is central to the multi-objective control approach in the CAPSM framework. A control solution is Pareto optimal if no objective can be improved without degrading at least one other objective.

The framework generates and analyzes the Pareto front—the set of all Pareto optimal solutions—to understand the trade-offs between objectives and support informed decision-making. This is achieved through several techniques:

  • Weighted Sum Method: Combining objectives with different weights to explore the Pareto front.
  • ε-Constraint Method: Optimizing one objective while constraining others to generate Pareto optimal points.
  • Multi-Objective Evolutionary Algorithms: Using genetic algorithms to generate diverse Pareto optimal solutions.
  • Normal Boundary Intersection: Systematically exploring the Pareto front by solving a series of optimization problems.

The Pareto front analysis provides valuable insights into the fundamental trade-offs in the control problem, such as the relationship between system security and economic efficiency.

9.5.3 Preference Articulation and Decision Support

While the Pareto front represents the set of all optimal trade-offs, selecting a specific operating point requires articulation of preferences among the competing objectives. The CAPSM framework provides decision support tools that help operators and automated systems express and apply these preferences.

Preference articulation is implemented through several approaches:

  • A Priori Methods: Preference information is specified before optimization, typically through objective weights or goal values.
  • Interactive Methods: Preferences are refined iteratively as the decision-maker explores potential solutions.
  • A Posteriori Methods: The entire Pareto front is generated first, and then the preferred solution is selected.

For automated decision-making, the framework implements a utility function approach where preferences are encoded as a utility function U(F) that maps the vector of objective values to a scalar utility:

U(F)=∑i=1mwi⋅ui(fi)

where wi are importance weights and ui are individual utility functions for each objective. These utility functions can be non-linear to reflect risk attitudes and sensitivity to different performance levels.

9.5.4 Trade-off Analysis Between Competing Objectives

Understanding the quantitative relationships between competing objectives is essential for effective multi-objective control. The CAPSM framework includes tools for analyzing these trade-offs and their implications for system operation.

Key trade-off relationships examined include:

  • Stability vs. Economics: The cost of maintaining higher stability margins through conservative operation.
  • Reliability vs. Efficiency: The relationship between system reliability and resource utilization efficiency.
  • Environmental Impact vs. Cost: The economic implications of reducing emissions and environmental footprint.
  • Customer Preferences vs. System Needs: Balancing individual user preferences with overall system requirements.

These trade-offs are quantified through sensitivity analysis that examines how changes in one objective affect others. For example, the marginal cost of stability improvement is calculated as:

MCstab=ΔCostΔStability=fcost(u2)−fcost(u1)fstab(u2)−fstab(u1)

where u1 and u2 are control solutions with different stability levels.

9.5.5 Dynamic Priority Adjustment Based on System Conditions

The relative importance of different control objectives can change significantly with system conditions. The CAPSM framework implements dynamic priority adjustment mechanisms that adapt objective weights based on the current state of the power system and external factors.

Priority adjustments are triggered by several factors:

  • Proximity to Operational Limits: As the system approaches stability or thermal limits, security objectives receive higher priority.
  • Market Conditions: During high price periods, economic objectives may become more important.
  • Weather and Environmental Conditions: Extreme weather may increase the priority of reliability objectives.
  • Time of Day and Season: Peak vs. off-peak periods may have different objective priorities.
  • Contingency States: Post-contingency operation prioritizes security and recovery objectives.

The dynamic adjustment mechanism is implemented through a rule-based system that modifies objective weights based on system conditions:

wi,t=wi,base⋅∏j=1kϕj(cj,t)

where wi,t is the weight for objective i at time t, wi,base is the baseline weight, cj,t represents condition j at time t, and ϕj is a function that maps the condition to a weight multiplier.

9.5.6 Validation Across Different System States

The effectiveness of the multi-objective balancing approach is validated across a diverse set of system states to ensure robust performance under varying conditions. The validation process examines both normal operating conditions and stressed system states.

The validation methodology includes:

  1. Scenario-Based Testing: Evaluating performance across predefined scenarios representing different system conditions and challenges.
  2. Monte Carlo Simulation: Assessing statistical performance across randomly generated system states.
  3. Sensitivity Analysis: Examining how small changes in system parameters affect the balance of objectives.
  4. Extreme Condition Testing: Validating performance under extreme and unusual operating conditions.

The validation metrics include both individual objective performance and meta-metrics that evaluate the quality of the multi-objective balancing:

  • Objective Satisfaction Ratio: Percentage of objectives that meet their minimum acceptable levels.
  • Fairness Index: Measure of how evenly the objectives are satisfied relative to their importance.
  • Regret Metric: Maximum normalized deviation from the optimal value of any individual objective.
  • Robustness Index: Stability of the multi-objective solution across perturbed system states.

Results from the validation across different IEEE test systems demonstrate that the adaptive multi-objective approach consistently outperforms fixed-weight approaches, with improvements of 15-30% in the fairness index and 20-40% in the regret metric.
